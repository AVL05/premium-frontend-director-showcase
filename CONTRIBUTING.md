# Contributing to The Art of Direction

This repository is the public showcase, not the distribution source for the Premium Frontend Director skill. Skill changes belong in [the upstream project](https://github.com/AVL05/premium-frontend-director).

## Local workflow
1. Use Node.js 22 or newer.
2. Run `npm install`, `npm run dev`, `npm run lint` and `npm run build`.
3. Review DESIGN.md before changing composition, typography, color, choreography or content.
4. Supply screenshots for desktop and mobile visual changes.
5. Verify keyboard navigation, responsive layouts, and reduced-motion on interactive changes.
6. Link to the source and license for new assets. Do not add fake case studies, metrics, awards or testimonials.

## Design review
Strong ideas require concrete browser evidence, not an invented numerical quality score. Report the actual checks you ran and any not run.

## Submitting changes
Keep pull requests focused and describe the why, before/after visuals, device coverage, and performance tradeoffs. No unaudited heavy animation dependencies.
